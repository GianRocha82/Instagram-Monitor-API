Para executar a API:

Windows (Recomendado)
cmd
cd "C:\Users\[local da API]"
start.bat


Linux/macOS
bash
cd "C:\Users\[local da API]"
chmod +x start.sh
./start.sh


Manual (Qualquer SO)
bash
1. Ativar venv
Windows:
venv\Scripts\activate
Linux/macOS:
source venv/bin/activate

2. Instalar dependências (se primeira vez)
pip install --upgrade pip
pip install -r requirements.txt

3. Iniciar servidor
python -m app.main



Após iniciar:
- Abra: http://localhost:8000
- Interface web com formulário de 6 passos
- Preencha:
