1 Perfil da Empresa Contratante

Forneça o link do Instagram da empresa que irá contratar os influenciadores. Coletaremos os primeiros 25 posts para criar uma base temática de referência.

2 Perfis Estratégicos para Monitorar

Adicione uma lista de perfis (influenciadores) que deseja monitorar. Mínimo 1, sem limite máximo.

3 Intervalo de Data

Selecione o período dos dados a serem analisados.

4 Modo de Coleta

Escolha como os dados serão coletados. Cada modo tem benefícios e limitações.

As credenciais são usadas apenas para autenticação no Instaloader e não são armazenadas.

5 Tipo de Monitoramento

⚠️ O monitoramento semanal realizará coletas automáticas a cada 7 dias por 30 dias, atualizando o arquivo CSV com novos posts detectados. Requer que a API permaneça rodando.

6 Local de Salvamento

Escolha onde o arquivo Excel (.xlsx) com as 3 abas (Postagens, Hashtags, Conteúdo) será salvo.

O arquivo será nomeado automaticamente: {perfil}_{tempo}_{data}.xlsx
